# تواسع — تخطيط حلقات تحفيظ القرآن الكريم

تطبيق ويب يعمل على الجوال والتابلت والديسكتوب (قابل للتحويل لتطبيق جوال لاحقاً)، يساعد معلمات حلقات التحفيظ على بناء خطط حفظ ومراجعة وطباعتها كملف PDF.

**النسخة الأولى:** تعمل في المتصفح مباشرة دون خادم ودون إنترنت، ودون حسابات.

---

## المصدر المعتمد لبيانات المصحف

| البند | القيمة |
|---|---|
| المصدر الرسمي | **QUL** — `https://qul.tarteel.ai` |
| التخطيط | مصحف **KFGQPC V4 (1441H print)** — **Layout 19** |
| المواد | (1) تخطيط الصفحات والأسطر، (2) بيانات كلمات V4 (بنيوياً فقط)، (3) أسماء السور (من QUL أو `quran-metadata` كمساعد موثق) |
| صيغة التنزيل | التخطيط: **SQLite** (هي المتاحة في واجهة QUL لهذا التخطيط) — الكلمات وأسماء السور: JSON |
| الفهرس المدمج | بيانات مرجعية/تخطيطية فقط — **بدون نصوص الآيات** |

- المواد المرجعية تُحفظ في `data/mushaf/` (قراءة فقط) وتُوثَّق في `data/qul-source-manifest.json` (مصدر + رابط + إصدار + تاريخ تنزيل + طريقة معاينة + هاش SHA-256).
- التطبيق لا يقرأ من هذه المواد أبداً؛ يقرأ من **الفهرس المدمج** في `src/data/` فقط.
- **لا يُخلط المصدر المعتمد مع أي مصدر آخر.**

## الأوامر

| الأمر | الغرض |
|---|---|
| `npm run dev` | تشغيل بيئة التطوير |
| `npm run build` | بناء التطبيق (تحقق الأنواع + البناء) |
| `npm test` | اختبارات الفهرس المدمج داخل الحزمة (تعمل دون مواد ودون شبكة) |
| `npm run test:mushaf` | اختبارات على مواد QUL الفعلية في `data/mushaf/` |
| `npm run build:mushaf` | بناء الفهرس المدمج من مواد QUL + التحقق (114/6236/604) + هاش SHA-256 |
| `npm run verify` | بوابة التسليم: `build:mushaf` ← `test:mushaf` ← `npm test` |

**لا يُسلَّم أي إصدار قبل نجاح `npm run verify`.**

## كيفية إعادة بناء الفهرس

1. تأكد من وجود مواد QUL في `data/mushaf/` واكتمال `data/qul-source-manifest.json`.
2. شغّل `npm run build:mushaf` — يتحقق (114 سورة / 6236 آية / 604 صفحات + استمرارية الترقيم بين الصفحات)، يبني الفهرس في `src/data/` بصيغة UTF-8 بلا BOM، ويحسب هاش الأثر.
3. شغّل `npm run test:mushaf` ثم `npm test` للتحقق.
4. لضمان التكرارية: تشغيلان متتاليان للبناء يجب أن يعطيا الهاش نفسه.

## كيفية فحص المواد يدوياً

قبل البناء الأول، يُراجع بشرياً عينة من الصفحات للتأكد من سلامة المواد:
- صفحة 1 (الفاتحة + البسملة سطراً مستقلاً).
- بداية سورة البقرة (صفحة 2).
- منتصف المصحف.
- صفحة 604 (نهاية الناس).

وتُسجَّل نتيجة الفحص في `data/qul-source-manifest.json`.
