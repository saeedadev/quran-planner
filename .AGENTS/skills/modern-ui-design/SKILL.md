# Modern UI Design

## Goal
Produce interfaces that feel premium, calm, and intentional — not like a generic AI-generated template.

## Rules
- Use a limited color palette: neutral background/surface colors plus one accent color used only for primary actions.
- Support both light and dark mode.
- Use consistent spacing (a 4px/8px spacing scale) — never random margin/padding values.
- Use a clear typography hierarchy: one font for headings, one for body text, no more than 3-4 font sizes per screen.
- Left-align body text and descriptions; only center short hero headlines or empty states.
- Avoid: purple/blue gradient backgrounds, glowing blob shapes, icons wrapped in colored circles repeated in a 3-column grid, colored left-border accents on cards, emoji used as icons.
- Prefer subtle shadows and neutral borders (soft, low-opacity) over harsh borders or bright dividers.
- Every interactive element (button, link, input) needs a visible hover/focus/active state.
- Design real empty states, loading states, and error states with the same care as the main content — never leave a bare "No data" message.

## Quick self-check before finishing a screen
- Is there more than one accent color visible at once? Reduce to one.
- Are all cards/buttons the same repeated shape with no visual hierarchy? Vary it.
- Does this look like a template you've seen before? If yes, simplify and make it more specific to this product.
